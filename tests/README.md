# Tests — ischu-svishchu CRM

Создано в ходе аудита 2026-07 (ветка `audit/2026-07`). Запускать перед КАЖДЫМ пушем в `main`.

## Запуск

```bash
node tests/run.js
```

Выход `0` — всё зелёное, можно пушить. Выход `1` — есть падения, пушить нельзя.

Требуется Node 18+ (нужны глобальные `Blob`/`atob`). Никаких зависимостей — только стандартная библиотека.

## Что внутри

| Файл | Что проверяет |
|---|---|
| `run.js` | Единая точка входа, сводка pass/fail |
| `extract.js` | Достаёт настоящие функции из `index.html` — тесты гоняют боевой код, не копии |
| `static.tests.js` | Синтаксис всех `<script>`-блоков; каждый `getElementById` находит свой элемент; нет ссылок на удалённые поля модалки «В базу»; «пины» на выражения поиска и защиту callAI |
| `unit.tests.js` | Дедупликация, merge со всеми комбинациями opts (включая охрану updateName), поиск по телефону/почте, migrateCandidate на старых данных, round-trip data URL → Blob |
| `regression.tests.js` | Пять багов, которые уже случались в проде — каждый закреплён тестом |
| `perf-bench.browser.js` | Бенчмарк производительности — вставить в консоль браузера (см. шапку файла). ТОЛЬКО на localhost или preview, НИКОГДА на боевом URL |

## Регрессии, которые закреплены

1. `_blobToDataUrl` без Promise → все бэкапы теряли файлы (2026-07)
2. `_detectKind` без `await` → 62/62 ошибок импорта (2026-07)
3. base64 в `files[].data` затирался `saveData` → файлы пропадали после перезагрузки (2026-06)
4. Кэш `_searchHay` сохранялся в IndexedDB → поиск «замерзал» на старом наборе полей (2026-07)
5. Двойной `addLog('Файл удалён')` (2026-06)
